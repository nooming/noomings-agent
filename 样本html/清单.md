# 样本html 清单

工作区中文文件夹 ↔ 平台 package id（`data/runtime/packages/{id}/game.html`）。

**离线双击包**：整夹拷贝（含 `vendor/`）后双击根目录 `index.html` 即可浏览试玩与图谱；说明见 `README-离线说明.md`。离线范围 = 试玩 + 图谱预览，≠ 登录 / 学情 / 评判。

**一样本一文件夹**：`样本html/<名>/` 仅含两份 HTML——游戏样本 `*.html` + `图谱.html`（Agent A Strategy-first 优先级可视预览）。`chapter.json` / `meta.json` 只留在 `data/runtime/packages/{id}/`。

## 审查注意（逐批抽检固定检查）

1. **开场不剧透混淆变量**：intro / 侧栏不得出现「质量为混淆」「不影响结论」等措辞；CV 控件可保留，标签写成普通物理量，让学生自己辨别。  
2. **探究中不直接给公式**：intro 不放公式；公式仅允许出现在过关后的 win 总结卡。  
3. **无多余装饰控件**：如「切换主题」这类一眼无关、又无叙事价值的按钮应删除。  
4. **对比度**：字色与背景需可辨（尤其 craft 深色壳上的灰字）。  
5. **过程可见**：有运动结论的样本须有动画/过渡，不能只有瞬时状态切换。  
6. **HUD 不互相遮挡**：双模式条、craft 仪表与游戏原生 HUD 不得重叠；发射/测试时读数须完整可见。  
7. **倒计时高对比**：`#timerDisplay` 与芯片背景对比清晰可辨。  
8. **精致度下限**：舞台与侧栏层次不应明显弱于同批旗舰（如斜抛）；禁止半透明块无布局地叠在读数上。  
9. **舞台有场景叙事**：舞台不能只是光秃秃物理示意图；须有可辨场所/道具（如斜抛大炮、摩擦卸货滑道），使学生一眼知道「在干什么」。纯几何示意且无叙事锚点视为不达标。  
10. **运动方向正确**：动画/轨迹方向须符合物理与场景叙事（如下滑须从高到低）；注释与参数约定不得和实际位移相反。  
11. **舞台像素清晰**：canvas 不得仅靠 CSS 放大低分辨率缓冲；位图尺寸须跟舞台（含 DPR），场景锐利度不应明显弱于侧栏 DOM。  
12. **道具相对位置合理**：场景内目标/落点/接货区等与运动终点几何一致，不得嵌进错误构件或叙事对不上。  
13. **构图与读数避让**：主场景应占满合理视觉中心、避免大片无意义留白；场景内读数不得被双模式条、标题条等外部 UI 遮挡。  
14. **初始条件有探究张力**：默认参数宜呈现「待解决问题」的状态（如摩擦初始卡住卸不下），避免一上来就得到结论态而失去调参动机。  
15. **轨迹方向符合物理叙事**：入环/上下环/左右升降等运动方向须与物理预期一致（可目视核对），不得只靠注释或参数名；左右镜像、正负角约定与画面位移须一致。  
16. **动画时序反映物理量**：速度/高度/能量变化类动画须体现快慢差异（如环底快、爬升慢、环顶最慢、下落加速）；禁止全程固定 duration 线性插值冒充动力学（明示「示意、非守恒」的除外）。  
17. **临界玩法须有上下界**：不仅「参数太小失败」，还要「太大也失败」（过冲、超速飞出、过热等），避免把滑条拉满即可过关；成功区应落在中间可探究带。  
18. **失败形态可区分**：多种失败（如能量不足掉落 vs 速度过大飞出）须有不同动画与观察文案/badge，避免一律「未过关」糊成一种体验。  
19. **终点收束叙事完整**：有运动终点的样本须有可见收束区（减速带、接货区、靶区等）；成功应停在/落在该区内，过大过冲应冲出该区并有对应动画，禁止中途莫名消失或飞走。  
20. **连续可读的结果梯度**：结局/收束不宜只靠少数离散卡通分支；停距、落点、冲出远近等运动结果应随物理量连续变化。学生须能靠目视距离/落点判断偏大偏小并调参；观察文案可辅助描述相对位置，但不替代可视反馈。  
21. **探究与竞赛参数/几何分流**：竞赛与探究的目标几何、收束区或容差带不得完全相同，避免学生把探究结论直接套用过竞赛；差异须目视或体验可辨，且本局 Fixed 内保持稳定（失败不换区、不换容差）。  
22. **禁止调参时用结果几何剧透**：不得在拖滑条过程中实时画出与当前参数绑定的结论几何（如当前轨道半径虚线、落点/轨迹预览、像距结论线、折射出射光路等），以免未测即见答案；任务目标区/提取环/靶区等可常显，场景道具随控件变化（如斜面倾角、物距位置）可保留。与测后读数门控一致：结果几何与数值读数均须测后或发射后才揭示；发射后的运动过程仍须可见（不与「过程可见」「动画时序」冲突）。
