## 历史原样（n=49）

来源：对话 transcript（约 2026-08 上旬会话级 PCA 重算与后续讨论）。仓库内**无**当时单独落盘的完整报告副本（后续 `radar-pca-analysis.md` 被学生级分析覆盖）。

### 构成与口径

- **n = 49** = pass **34** + exhausted_fail **15**
- **单位**：终局会话；**不含 incomplete**
- **人数量级**：约 16 人；主体为 **全检 / 验收** 轨迹，外加少量 **李四、王五**
- **4D 向量**（abilityScore **v3**）：`[结果, 探究过程, 竞赛过程, 效率]`
- **不做**：一致性、完成度（跨局/人级指标，单局无可靠代理）
- **过滤**：去掉 `playtest` / `full-eval` / `全量*` / 匿名 junk；**保留全检**与真实学生标签
- **缺失**：对话中曾述列均值填补（与后来 v4 稀疏下「填 0」不同）

### PCA 方差与命名（历史）

| 主成分 | 方差比 | 累计 | 当时命名建议 |
|---|---:|---:|---|
| PC1 | **60.3%** | 60.3% | 整局能力公因子 |
| PC2 | **20.4%** | 80.7% | 深探究 vs 结果得分 |
| PC3 | **15.7%** | 96.4% | 结果—探究 vs 竞赛—效率 |

- ≥80% 约需 **2** 个主成分；≥90% 约需 **3** 个
- **载荷读法（历史）**：
  - PC1：四维同向；竞赛/效率载荷相对大 → 「这一局整体强不强」
  - PC2：探究与结果符号相反 → 「深摸索 vs 冲结果」风格轴
  - PC3：结果+探究 vs 竞赛+效率 → 「探究侧 vs 竞赛侧」

### 对方命名 vs 载荷（历史结论）

对方曾命名「探究能力 / 学习兴趣 / 学习动机」——**与载荷不符**，不宜当定论：

| 对方叫法 | 数据实际 | 结论 |
|---|---|---|
| PC1「探究能力」 | 四维同涨，探究并非最大载荷 | 不合适 → 更像整局综合 |
| PC2「学习兴趣」 | 探究高 ↔ 结果相对低 | 牵强 → 玩法风格，非兴趣量表 |
| PC3「学习动机」 | 探究侧 vs 竞赛侧 | 更牵强 → 动机测不出 |

### 当时已指出的局限

1. **外部效度**：全检/验收偏多（故意失败、用尽、少通关）≠ 真实课堂  
2. **观测不独立**：同一人多局当多行，自由度偏乐观  
3. **终局偏斜**：pass≈34 / exhausted≈15，可能放大 PC2「过程 vs 结果」  
4. **包效应**：跨多种物理包，相关可能混进任务难度/埋点差异  
5. **探索性用途**：可看方向与共变；**不够**支撑稳定教学命名或产品改轴  

### KMO

- **历史未算**。KMO 是后来才加入分析管线的；git / 旧报告中**不存在**「n=49 当时的 KMO」。

### 数据下落（原始 49 包）

- 当时轨迹在 `data/runtime/platform/traces/`（通常 **gitignore，不进 git**）
- 仓库与本机现有导出：`traces-全部-20260811/12/13` 等，**不是**独立的「49 会话」文件夹或 zip
- `traces-全部-20260811` 曾核对：约 68 文件、终局约 31，**≠** 当年 n=49 全检样本
- **结论**：分析数字可从对话核对；**原始 sess 文件无法从 git 恢复**；若仍存在，只能查部署服旧库或当时另存导出

## 近似复算（n=51）

完整数字与进样清单见 [`session-pca-kmo-approx49.md`](./session-pca-kmo-approx49.md)。  
`radar-pca-analysis.md` 附录仅作摘要指针，**不覆盖**学生级主结论。

### 与历史的口径差异

| 项 | 历史 n=49 | 近似 n=51 |
|---|---|---|
| 数据源 | 平台当时 traces（已失） | `traces-全部-20260813`（112 文件） |
| 能力分 | v3 | v4（缺维贡献 0） |
| 结果维 | 「结果」 | 优先 `challengeResult`，否则 legacy `result` |
| 进样门槛 | v3 有限总分（对话记忆） | v4 有限总分 + 竞赛结果 raw 有限 |
| 缺失 | 列均值（记忆） | **填 0**（v4 下 Pe/E 极稀，列均值会压成近常数） |
| 结局构成 | pass 34 / exh 15 | pass 26 / exh 25 |
| KMO | 无 | **0.549** |

差异可能来自：分版 v3→v4、终局池变化、junk 规则、打包日期、填补策略——**故 n=51 是近似，不能当作历史存档 KMO/PCA 原样。**

### 筛选逻辑摘要（`scripts/session-pca-kmo-approx49.js`）

1. 读 traces 根目录学生/会话列表；剔除 synthetic junk（`playtest` / `full-eval` / `全量*` / 匿名等），保留李四/王五等  
2. 只要 `terminalOutcome ∈ {pass, exhausted_fail}`  
3. 要求 abilityScore **v4**、非 pending、`total` 有限  
4. 抽出 4D；竞赛结果必须有限才进样  
5. 缺失 raw → **0**；等权 Pearson → KMO/MSA/Bartlett + 等权 PCA  
6. 另报「四维均有限、不填补」严格对照（v4 下常仅 n≈1，不作主数字）  
7. 写入 `session-pca-kmo-approx49.md`，并在 `radar-pca-analysis.md` 追加附录指针  

### KMO / MSA（近似主数字）

- **整体 KMO = 0.549** → 很差 / 勉强边缘（0.5–0.6）
- MSA：竞赛结果 0.664；探究过程 0.533；竞赛过程 0.629；效率 0.532  
- Bartlett：χ²≈20.27，df=6，p≈0.0025（相关结构存在）  
- 对照：学生级主六维 KMO≈**0.337**（不适合）——会话级 4D 相关更紧，但仍属边缘探索

### PCA（近似）

| 主成分 | 特征值 | 方差比 | 累计 | 命名建议 |
|---|---:|---:|---:|---|
| PC1 | 1.6801 | **42.0%** | 42.0% | 探究过程—效率共变 |
| PC2 | 1.0430 | **26.1%** | 68.1% | 竞赛侧（结果+过程） |
| PC3 | 0.8231 | **20.6%** | 88.7% | 竞赛结果 vs 竞赛过程 |
| PC4 | 0.4538 | 11.3% | 100.0% | — |

载荷（节选）：

| 维度 | PC1 | PC2 | PC3 |
|---|---:|---:|---:|
| 竞赛结果 | -0.380 | 0.507 | 0.768 |
| 探究过程 | 0.620 | 0.331 | 0.172 |
| 竞赛过程 | -0.252 | 0.747 | -0.615 |
| 效率 | 0.639 | 0.275 | 0.048 |

≥80% 需 3 个 PC；≥90% 需 4 个。缺维填 0 极重（约 50/51 局有缺失），解读宜保守。

### 与历史对照表

| 指标 | 历史 n=49 | 近似 n=51 |
|---|---|---|
| PC1 方差 | 60.3% | 42.0% |
| PC2 方差 | 20.4% | 26.1% |
| PC3 方差 | 15.7% | 20.6% |
| 累计至 PC3 | 96.4% | 88.7% |
| PC1 命名气质 | 整局公因子（四维同向） | 探究—效率共变（结果载荷符号不同） |
| KMO | （无） | 0.549 |

**勿**把近似的 42% / 0.549 说成「当年 49 的结果」。
