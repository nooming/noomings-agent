# 过程性评价 · 教师半页说明

面向课堂快速读数：平台评的是**探究过程**，不是搜题答案对错。

## 平台评什么

- **路径类型**：主推 / 误区 / 教案等策略途径（是否沿约束链收敛）
- **变量调节**：有效参（AV）怎么拧、是否混调、竞赛段有无对照
- **是否达标**：是否触发过关（win）；达标不等于探究充分

学生过关页会**自动出示本局证据**（读数与主调节摘要），学生只补一句短归因；公式与无关量说明后置揭示。界面不使用「CER」作标题。

## 界面上怎么读

1. **路径摘要**：会话详情里的探究路径 / 策略分，看学生更像单参对照还是多参盲调。
2. **变量表**：AV 调节次数、CV（混淆/旁路）试探次数；CV 偏重说明在拧无关量。
3. **规则评判 strengths / gaps**：
   - strengths：合理试错、单参习惯、收敛等
   - gaps：旁路试探、混调、**过关偏少对照**（已过关但有效对照不足，建议同一变量多测几次）等

默认规则评判即可；有 Key 时可用 LLM 补充话术，字段仍是 strengths / gaps。

## 附录：与「观点 / 证据 / 论证」的粗映射（教研汇报可选）

| 课堂说法 | 平台落点 |
|---------|---------|
| 观点（学生主张） | 过关页短归因点选；非必填大段文字 |
| 证据 | 轨迹读数自动出示（高度/射程、主调控件与次数、是否命中等） |
| 论证 | 教师侧 strengths/gaps + 路径摘要（系统侧过程评语） |

正文与 UI 不使用 Claim / Evidence / Reasoning 字段名，也不以「CER」作产品品牌。
