## 2.3 关键数字（照抄报告）

### A. 历史会话级（存档，ability **v3**）

- **n = 49** = pass **34** + exhausted_fail **15**（不含 incomplete）
- **KMO**：当时 **从未计算**（不可写「n=49 的 KMO=…」）
- **方差比**：PC1 **60.3%**、PC2 **20.4%**、PC3 **15.7%**（累计约 **96.4%**）
- **历史命名倾向**：PC1 整局能力公因子；PC2 深探究 vs 结果；PC3 探究侧 vs 竞赛侧
- **局限**：全检/验收偏多；同一人多局不独立；原始 49 个 sess **无法从 git 恢复**

### B. 现复算会话级（`traces-全部-20260816`，ability **v4**，缺维填 **0**）

- **n = 54** = pass **29** + exhausted_fail **25**
- **整体 KMO = 0.507**（很差 / 勉强边缘 0.5–0.6）
- **Bartlett**：χ² = 43.39，df = 6，p = 9.78e-8
- **方差比**：PC1 **45.1%**、PC2 **27.8%**、PC3 **20.7%**（PC4 6.4%）
- **载荷命名建议（报告）**：PC1 探究过程—效率共变；PC2 竞赛侧（结果+过程）；PC3 竞赛过程 vs 竞赛结果
- **与历史差异**：n、pass/fail 比、PC1% 均不同（v3→v4、填 0 vs 旧列均值等）；**PC1 不必等于 60%**
- **严格不填补对照**：四维 raw 均有限仅 n=4，KMO=0.000 — **不作主数字**

### C. 学生级主六维（对照）

- 进矩阵 **n = 13**；**整体 KMO ≈ 0.337**（不适合 &lt;0.5）
- 软降权主分析方差：PC1 **39.4%** / PC2 **22.7%** / PC3 **21.4%**
- 报告结论：更宜描述性雷达，**不宜硬抽稳定因子**

## 2.6 百人复测设计要点（一句 + 清单）

**一句话**：在真实课堂招募约 **≥100 名**学生、每人有限终局会话、预先冻结进样与填补协议、汇报 KMO/MSA 与会话级/学生级双单位，验证载荷命名是否可复现——再谈构念与产品改轴。

要点清单：

1. **单位**：主报会话级与学生级分开；同一人多局要报告 ICC 或改用学生级。  
2. **结局**：明确是否含 incomplete；与现报告一致则只进 pass / exhausted_fail。  
3. **分版**：锁定 abilityScore 版本与缺维规则（填 0 vs 列均值）并预注册。  
4. **适合度**：KMO / MSA / Bartlett 必报；边缘则只写探索性。  
5. **效标（可选）**：前后测或教师评分，用于外源效标而非替换日志。  
6. **伦理与知情**：课堂数据脱敏；区分验收轨迹与课堂轨迹。

## 2.7 给老师的三句（可直接说）

1. 我们做的是**过程日志多维指标的探索性 PCA**：会话级现样本 n=54、KMO=0.507（边缘）；学生级 KMO≈0.337（不适合硬抽因子）。  
2. **探究达成 ≠ 竞赛通关**；主成分宜按载荷叫「过程—效率共变 / 竞赛侧」等，口头「动机 / 解决问题 / 操作」只作教学解读。  
3. 历史 n=49（PC1≈60%）是沿革存档且**当时无 KMO**；正式论文需百人级、协议冻结后再谈稳定结构。
