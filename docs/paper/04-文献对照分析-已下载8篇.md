## 1. 方法补强题录（6 条，2026-10 检索）

> 写入 Related work **§2.7** 或 Discussion「形成性/量规」；**勿**声称已精读除非 PDF 入库。

### B1. Gamebrics — 游戏内分析性量规与反思性反馈

- **题名**：Gamebrics: Design, implementation and practical evaluation of analytical rubrics in serious game play  
- **期刊**：*Journal of Computer Assisted Learning*（DOI: [10.1111/jcal.12998](https://doi.org/10.1111/jcal.12998)）  
- **为何相关**：将 **量规/反思反馈** 嵌入严肃游戏过程；对照本平台 **规则诊断 + strengths/gaps**（非嵌入量规 UI，但同属形成性读数）。  
- **对你**：Method 写「规则形成性出口」；Discussion 对比「他们 dashboard 反馈 vs 我们 formativeAssessment 规则包」。  
- **获取**：待校园网下载

### B2. Serious Game Analytics by Design（Mission HydroSci）

- **作者**：Alonso-Fernández 等（JLA 同团队）  
- **题名**：Serious Game Analytics by Design: Feature Generation and Selection Using Game Telemetry and Game Metrics  
- **期刊**：*Journal of Learning Analytics*（[10.18608/jla.2022.7681](https://doi.org/10.18608/jla.2022.7681) 或 JLA 页面 `/article/view/7681`）  
- **为何相关**：**telemetry 与教学干预信号** 同设计；对照 `inquiryScript` / traceMap **设计轨与分析轨对齐**。  
- **对你**：Related work「GLA 设计闭环」；勿写成预测模型主结果（本文主结果仍是 PCA 结构）。  

### B3. LA × Formative Assessment 系统综述

- **题名**：Learning analytics in formative assessment: A systematic literature review  
- **DOI**：[10.21031/epod.1272054](https://doi.org/10.21031/epod.1272054)  
- **为何相关**：LA 支撑 FA 的反馈、进度监控、风险识别；锚定 **三出口** 中诊断层的文献位置。  
- **对你**：Introduction/Related work 一句「过程日志用于形成性评价而非仅 summative」。

### B4. 开放仿真中的实验「系统化」日志指标（CVS 连续尺度）

- **题名**：Measuring systematicity of students' experimentation in an open-ended simulation environment from logging data  
- **来源**：Concord Consortium 技术报告/PDF（[concord.org 出版物链接](https://concord.org/wp-content/uploads/publications/measuring-systematicity.pdf)）  
- **为何相关**：从日志度量 **控制变量/系统化试次**（sample entropy）；对照本平台 **单参对照、旁路 CV、Pe/路径** 的操作化。  
- **对你**：Method/Discussion **一句**区分「中学 CVS 选项测验 vs 大学 AV/CV 轨迹」（与 `process-detectors.md` 一致）；**不**声称复现该 entropy 指标。

### B5. 虚拟实验各阶段 CVS（日志）

- **题名**：Control of Variables Strategy Across Phases of Inquiry in Virtual Labs  
- **出处**：Springer 章节（[10.1007/978-3-319-93846-2_50](https://link.springer.com/chapter/10.1007/978-3-319-93846-2_50)）  
- **为何相关**：探究 **collect / plot** 等阶段的 CVS 与模型质量；对照 **双阶段 explore/challenge** 分工。  
- **对你**：Related work 短段；强调本文 **分阶段达成**（explore_success vs win）。

### B6. 仿真日志自动化评估问题解决实践（L@S）

- **题名**：Automating the Assessment of Problem-solving Practices Using Log Data and Data Mining Techniques  
- **会议**：L@S 2021（[10.1145/3430895.3460127](https://doi.org/10.1145/3430895.3460127)）  
- **为何相关**：**知识引导特征** + 日志预测实践采纳；对照 **规则评判 + 图谱对齐**（非同一方法，可写方法谱系）。
