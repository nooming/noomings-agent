# 热学试点口播要点（gas + heat）

> 课堂默认只上架两条热学：`demo-gas-ideal`、`demo-heat-conduction`。  
> **不做**整关新玩法；本页供老师 2–3 分钟口播 / 演示串衔接。更完整演示清单见 [classroom-demo-checklist.md](./classroom-demo-checklist.md)。

---

## 为什么先这两条

| 关卡 | 一口话 | 演示角色 |
|------|--------|----------|
| **气室 · 理想气体** | 等温下看 `p·V` 是否近似常数 | 热学开场，对照「调参 → 读数」 |
| **热工台 · 热传导** | 热流随 κ、ΔT；合适区间才稳妥 | 热学第二关，对照公式 `Q/t=κAΔT/d` |

力学主串（斜抛 → 秒摆 → 可选摩擦）讲完后，用这两关说明「热学也能探究 / 竞赛双模」，不必扩到相变、比热等新关。

---

## 口播要点（建议 ≤3 min/关）

### gas-ideal

1. **探究**：只改压强或只改体积，看乘积怎么走；对照「等温」假设。  
2. **竞赛**：标定带本局锁定，限次打进带。  
3. **旁路**：活塞质量滑条标「不进 pV 判定」——拧了读数不变，用来练控制变量。

### heat-conduction

1. **探究**：主拧导热系数 κ 与温差 ΔT，看穿墙热流。  
2. **竞赛**：安全带内才过关（太小不够暖、太大过热）。  
3. **旁路**：截面积 A **本关不进判定**（物理用固定 A）；口头强调「公式里有 A，但本关滑条是对照旁路」。
